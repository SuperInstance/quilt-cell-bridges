# Synergies: Quilt ↔ SuperInstance Fleet

These bridges connect Quilt to the larger **SuperInstance** ecosystem — 1,431+ repos, 9 active agents, 2,489+ tests, 18+ languages.

The Quilt and the SuperInstance Fleet are the same system seen from two angles. Quilt is the cellular formalism. SuperInstance is the fleet. They share the same conservation law, the same room abstraction, the same inter-agent protocol, the same A2A bridge, the same agent lifecycle, the same hermit crab principle, the same multi-layer reasoning, the same spectral methods, the same address-as-identity principle, AND the same spreadsheet cells.

## The Conservation Law Bridge (key result)

`conservation_to_quilt.py` proves that the SuperInstance's γ+H=C and Quilt's γ+η=C are **the same law**. `noether_guard_to_quilt.py` extends this by applying Noether's theorem: the symmetry (cell graph transformations) implies the conservation (γ+η=C). The drift detection and RG-style renormalization are exactly what Quilt's GC primitive does.

## The Spreadsheet Bridge (new!)

The SuperInstance spreadsheet-engine is a Rust crate with 7 cell types: Value, Agent, Training, Simulation, A2A, MIDI, Formula. Each maps exactly to Quilt primitives:
- Value → Z_in + Z_out
- Agent → DoubleEntry (γ+η=budget)
- Training → Vibe + JEPA
- Simulation → Vibe + Graph
- A2A → Murmur
- MIDI → Z_out
- Formula → JEPA

The 6 evolutionary formulas (EVOLVE, SPECIES, PARETO, ENTROPY, CORRELATE, CONSERVE) are Quilt formulas with the conservation law baked in.

## The Murmur Bridge (new!)

`murmur_agent_to_quilt.py` maps the murmur-agent's 5 thinking strategies to 5 Quilt primitives:
- Explore → Z_in (input from many sources)
- Connect → Graph (topology between thoughts)
- Contradict → JEPA (predicts + finds tensions)
- Synthesize → DoubleEntry (consolidates the budget)
- Question → Vibe (the meta-state that asks)

The Knowledge Tensor IS a Quilt cell graph.
